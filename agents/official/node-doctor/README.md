# IAMINE Node Doctor

`iamine.beta.node-doctor` is the first functional P0 reference agent. It
explains bounded, redacted IAMINE node-readiness evidence through the official
Rust runtime path.

The package is local-only, read-only, manual-review-only, and not published to
the public beta or marketplace. It cannot execute shell commands, use the
network, start workers, load models, mutate node state, or collect private host
data.
