# Photo Library Organizer Boundary Evals

The package-relative suite covers the nine canonical scope classes, including
the role-confusion and cross-domain requests that belong to other official
agents. Runtime tests add typed-input bounds, privacy, unsupported-claim,
missing-evidence, package-integrity, and zero-side-effect checks.

All fixtures are synthetic and must not contain raw prompts, logs, photo paths,
image bytes, EXIF or GPS values, credentials, host identifiers, or private
machine data.
