# V0.9-BETA-FRESH-INSTALL-E2E-001

## Objective

Prove that a freshly installed IAMINE LAN beta package can exercise the
repository-level private-testnet readiness path from an isolated operator
prefix.

This feature is a packaging and QA harness feature. It does not add runtime
behavior, start services, load models, download models, or run real inference.

## Scope

This feature adds:

```text
scripts/v0.9-fresh-install-e2e.sh
docs/architecture/v0.9-beta-fresh-install-e2e.md
docs/qa/v0.9-beta-fresh-install-e2e.md
```

It may update roadmap and release-gate documentation to reference the new
fresh-install E2E gate.

It must not change scheduler, P2P, worker, model, remote inference, admission,
or observability runtime behavior.

## Harness Flow

The harness performs these steps from a clean checkout:

1. Run focused private-testnet tests unless `--skip-cargo-tests` is provided.
2. Build `iamine-node`, or reuse an operator-provided binary with `--binary`.
3. Assemble a LAN beta package with `scripts/lan-beta-package.sh`.
4. Install the package into a temporary isolated prefix.
5. Run the package-local `first-run-preflight.sh`.
6. Execute installed CLI smokes for help, identity, config, cluster status, and
   zero-request testnet load-resilience stress.
7. Emit stable summary lines:

```text
V09_FRESH_INSTALL_E2E_STATUS=pass|warn|fail
V09_FRESH_INSTALL_E2E_PASS_COUNT=<n>
V09_FRESH_INSTALL_E2E_WARN_COUNT=<n>
V09_FRESH_INSTALL_E2E_FAIL_COUNT=<n>
```

## Runtime Boundaries

The harness must not:

- install, enable, start, stop, or restart system services;
- start workers;
- start P2P;
- start PubSub;
- download models;
- load models;
- run real inference;
- persist operator host identifiers in repository files.

The identity and config checks use temporary state paths. The first-run
preflight may run `cluster status --json` unless `--skip-lan-smoke` is passed.

## Validation Contract

The local validation contract is:

```bash
bash -n scripts/v0.9-fresh-install-e2e.sh
scripts/v0.9-fresh-install-e2e.sh --skip-lan-smoke
git diff --check
git diff --cached --check
```

The full private-testnet field contract remains separate. This harness proves
fresh package assembly, isolated install, first-run diagnostics, identity,
config, cluster status, and zero-request resilience smoke from the installed
artifact. It does not prove the future 10-50 node, 3-10 operator, multi-network,
two-to-four-week operational soak.

## Risks

- Hosts without `python3` cannot validate JSON payloads.
- First-run preflight can warn on intentionally unconfigured local hosts.
- `--skip-lan-smoke` narrows the check to isolated-host readiness and must be
  reported as such.
- A passing zero-request stress smoke does not prove real worker availability
  or real remote inference execution.
