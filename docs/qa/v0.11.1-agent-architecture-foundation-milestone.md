## Required Contract Validation

Confirm:

- the official roadmap order and scope-bound rule are unchanged;
- Rust types remain the root manifest source of truth;
- YAML authoring, generated JSON Schema, and typed deserialization agree;
- root parsing remains bounded, deterministic, and privacy-safe;
- referenced metadata paths remain package-relative and are not opened;
- architecture contracts do not claim runtime execution;
- scope, permissions, blocked actions, handoff, audit, resources, language,
  dependencies, and boundary eval contracts cross-reference consistently;
- no contract silently assumes another gate's ownership;
- package loading and agent execution remain unavailable at this milestone.

Also validate:

- valid and invalid root manifest fixtures;
- generated schema against canonical Rust types;
- input size, traversal, unknown fields, and blocked execution claims;
- privacy-safe diagnostics;
- roadmap and architecture link integrity;
- repository artifact, secret, and architecture-size guards.

Failures and warnings must be compared with the exact prior baseline. An
accepted exception cannot cover parser/schema divergence, unsafe references,
privacy leakage, or a false execution claim.

## Field QA Decision

TS140 and Proxmox are not required if Architecture confirms the final milestone
scope remains architecture contracts plus the deterministic in-memory parser.

If the authorized diff includes runtime, filesystem, worker, scheduler,
network, inference, hardware, packaging, or service behavior, stop and require
a revised field QA matrix.
