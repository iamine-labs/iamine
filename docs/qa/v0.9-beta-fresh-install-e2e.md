Expected:

- package assembly succeeds;
- isolated install succeeds;
- installed `iamine-node --help` succeeds;
- first-run preflight returns `pass` or `warn`;
- identity init/status JSON is parseable and reports no runtime side effects;
- node config status JSON is parseable and reports no runtime side effects;
- cluster status JSON is parseable;
- zero-request testnet load-resilience stress passes;
- no generated logs, packages, or local state are committed.

## Field QA Decision

Mac local QA is required for this feature. TS140 and Proxmox/R5500 validation
are recommended before claiming the package flow is portable across field hosts.

Do not run Proxmox/R5500 QA unless the operator confirms the guests are
available.
