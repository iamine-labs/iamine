## CHECK 2 - Scope And Architecture

`iamine-agent-runtime`. The current runtime supports bounded one-shot execution
of an exact authorized and loaded subject through a registered official Rust
program. It does not claim or provide:

- arbitrary binaries, scripts, shell commands, or dynamic code loading;
- active OS isolation, containers, credentials, or unrestricted filesystem;
- network transport, LAN discovery, remote agent dispatch, or scheduler wiring;
