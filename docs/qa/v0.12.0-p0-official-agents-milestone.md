# IAMINE v0.12.0 P0 Official Agents Milestone QA

Gate feature:

```text
V0.12.0-P0-OFFICIAL-AGENTS-MILESTONE-QA-001
```

Gate state:

```text
PROPOSED / BLOCKED
```

## Blocking Reason

The six P0 skeleton contracts are closed, but they are non-executable and not
user available. Functional agents, the Node Doctor evidence provider, and
executable runtime prerequisites do not yet have complete implementation and
validation evidence.

Skeleton QA cannot close the functional P0 milestone.

## Functional Agent Scope

The gate must include every functional P0 official agent promised by v0.12.0:

```text
NODE-DOCTOR-AGENT-001
REPORTER-AGENT-001
LAN-FILE-SHARE-ASSISTANT-AGENT-001
PHOTO-LIBRARY-ORGANIZER-AGENT-001
HOME-NETWORK-ASSISTANT-AGENT-001
WINDOWS-OPTIMIZER-ASSISTANT-AGENT-001
```

It must also validate:

```text
NODE-DOCTOR-EVIDENCE-PROVIDER-001
all executable v0.11.2 runtime prerequisites
package admission and load gates
scope and permission enforcement
audit, sandbox, lifecycle, timeout, cancellation, and handoff
routing and out-of-scope behavior
```

## Entry Criteria

Architecture must not authorize this gate until:

- every functional P0 feature is merged, validated, and closed;
- each agent has a canonical manifest and validated referenced metadata;
- every runtime prerequisite has executable evidence rather than only a
  documentation contract;
- the evidence provider is bounded, structured, redacted, read-only, and
  demonstrably non-agent;
- local, LAN, and remote modes are explicit for each agent;
- unresolved defects, test gaps, and baseline exceptions are listed;
- Mac, TS140, and Proxmox/R5500 are available for the approved matrix.

## Per-Agent Exhaustive Matrix

Every functional P0 agent must pass:

```text
positive capability tests
negative capability tests
scope boundary tests
permission boundary tests
blocked-action tests
unsafe-action tests
prompt-injection tests
role-confusion tests
privacy-redaction tests
handoff tests
timeout and cancellation tests
resource-bound tests
local/LAN/remote policy tests
audit-evidence tests
cleanup and no-side-effect tests
```

The gate fails if an agent exceeds scope, requests unjustified permissions,
executes destructive behavior by default, bypasses a blocked action, exposes
private evidence, accepts role confusion, or cannot refuse or hand off.

## Cross-Agent And Runtime Matrix

Validate:

- deterministic routing to an eligible specialized agent;
- refusal when no agent is eligible;
- no capability inflation from skeleton or manifest self-claims;
- no permission or evidence transfer between unrelated agents;
- isolation of cancellation, timeout, resources, and audit records;
- no cross-agent prompt injection or role confusion;
- bounded concurrency and cleanup;
- existing node, model, network, inference, installer, and diagnostics
  regression paths.

This is Agent Expert Routing, not distributed model MoE.

## Required Local Validation

Run the canonical quality gate, workspace tests, all agent and runtime suites,
schema and package validation, agent E2E harnesses, CLI smokes, security guards,
privacy checks, and architecture size guards against the exact authorized tree.

Record test counts per agent and per runtime owner. Compare every failure and
warning with the exact v0.11.2 closure baseline.

## Field QA

Mac, TS140, and Proxmox/R5500 are mandatory because this milestone claims
functional agents and executable runtime behavior.

The matrix must prove:

- local-only behavior stays local;
- LAN-only behavior does not reach public networks;
- remote behavior uses admitted, authenticated, compatible peers;
- CPU-only, GPU-capable, VM, cgroup, and constrained-node decisions remain
  compatible;
- no real model load is used in mock or negative safety tests;
- real inference is used only where the approved E2E contract requires it;
- no existing workers, models, profiles, credentials, or user files are
  modified by QA.

## Product E2E

Exercise installation or update through agent discovery, permission display,
scope display, task routing, execution or refusal, handoff, audit evidence,
result display, cancellation, cleanup, and restart where those surfaces are
promised by the milestone.

## Required Result

The only positive QA recommendation is:

```text
READY FOR ARCHITECTURE MILESTONE CLOSURE REVIEW
```

Architecture may close v0.12.0 only after the exact gate evidence is merged and
post-merge validation passes.
