# v0.7 Foundations Closeout

## Scope

This document records the Milestone 0 / v0.7 product closeout evidence that
allows IAMINE to begin the installable LAN beta line.

## Closed Product Features

The original v0.7 product features are closed in `develop`:

| Feature | Evidence |
| --- | --- |
| NODE-HARDWARE-PROFILER-001 | `42bfcd0` |
| MODEL-HARDWARE-COMPATIBILITY-001 | `a8bcfca` |
| MODEL-TRUSTED-REGISTRY-INTEGRITY-001 | `9413aa1` |
| MODEL-BETA-REGISTRY-METADATA-001 | merge `62b7667` |
| MODEL-CATALOG-SELECTION-CLI-001 | merge `4eb6730` |

Complementary model admission and runtime wiring gates remain closed as
recorded in the product roadmap.

## Exit Gate Evidence

Milestone 0 exit criteria are satisfied by the current `develop` line:

- approved beta models have verified immutable artifact metadata;
- new downloads fail closed when metadata is absent or contradictory;
- the catalog explains compatibility and admission gates;
- requested downloads do not silently bypass policy or substitute another model;
- Mac local validation and TS140 field validation passed for the catalog flow;
- Proxmox/R5500 was not required for the catalog CLI because the feature did
  not change runtime, worker, scheduler, broadcast, inference execution, or
  hardware profiling behavior.

## Remaining Non-Blockers

- Existing Rust and clippy warnings remain historical and are not new v0.7
  regressions.
- Optional local tools such as `cargo audit`, `cargo deny`, and `gitleaks` may
  be unavailable and must be reported as skipped when absent.
- TS140 shell sessions may not load the user cargo bin directory into `PATH`;
  `rg` was absent during the catalog CLI field check. That is a QA harness
  gap, not product behavior.

## Closeout Decision

Milestone 0 / v0.7 foundations are closed for the purpose of starting
Milestone 1 / v0.8 LAN beta contract work.
