## Scope

This document records the v0.10 pre-public infrastructure readiness package. It
does not add runtime behavior. It consolidates already-merged v0.10 features and
decides whether IAMINE can proceed into v0.11 Agent Network foundations.

This gate does not launch public beta, open public onboarding, publish release
artifacts, publish bootnodes, enable public support intake, or authorize public
reward eligibility.

## Readiness Gate

The v0.10 repository readiness gate must prove:

- all v0.10 feature rows are closed in the roadmap;
- each feature keeps its own architecture ownership boundary;
- public-testnet admission, updates, supply chain, rollback, diagnostics, and
  public docs remain pre-public contracts;
- README and public docs do not imply public onboarding is open;
- v1.0 remains `IAMINE Agent Network Public Beta`;
- v0.11 Agent Network features remain proposed and scope-bound;
- this gate does not change runtime code;
- generated logs and local QA artifacts are not committed;
- optional security tools are reported as skipped when unavailable;
- environmental warnings, especially local disk exhaustion, are explicitly
  classified.
