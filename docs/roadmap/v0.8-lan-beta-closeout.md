## Scope

This document records the Milestone 1 / v0.8 release-gate evidence for the
installable LAN beta. It does not add new runtime behavior. It closes only when
the milestone QA matrix proves the beta contract across local, TS140, and
Proxmox/R5500 environments.

## Release Gate

The beta release gate must prove:

- clean install or upgrade path;
- one to five workers;
- real inference over LAN;
- diagnostics before runtime;
- reboot recovery;
- worker stop, restart, and readiness recovery;
- bounded failure recovery;
- rollback path;
- privacy-safe support evidence.
